CosyVoice CosyVoice-v3.5-plus 音色克隆详解

CosyVoice 模型概述

阿里云 CosyVoice 系列是通义千问团队推出的语音合成模型，重点聚焦音色定制能力。 CosyVoice-v3.5-plus 是该系列最新旗舰，同时支持三种音色获取方式：

🔊 系统预置音色

直接使用的内置音色库，开箱即用，适合快速集成。

即时可用 无需额外配置
🎙️ 音色克隆

提供一段目标说话人的音频样本，模型复刻该音色。

需音频样本 高度还原
🎨 音色设计

用文字描述想要的音色特征，模型生成全新音色。

无需录音 从零创造

音色克隆（Voice Cloning）详细流程

  1. 准备音频样本：提供一段目标说话人的清晰语音（建议 3–60 秒，纯语音无背景噪音，采样率 ≥ 16kHz）。
  2. 调用 voice-enrollment 服务注册音色：通过 TTS 音色管理 API 上传音频，获得一个 voice_code（音色标识）。
  3. 使用克隆音色合成：在 TTS 请求中指定 voice 参数为克隆得到的 voice_code，模型会以该音色进行合成。
  4. 支持指令控制：合成时可附带 instructions 指定语气、情绪、语速等（如 "用温柔缓慢的语速播报"）。
CosyVoice v3.5-plus 核心能力： 音色克隆 + 音色设计 + 指令控制 + SSML（语音合成标记语言）+ LaTeX 公式朗读。 单次合成延迟极低，支持流式 WebSocket 和一次性 HTTP 两种 API 模式。

当前音色可见性逻辑

目前所有音色对所有公司可见，筛选仅通过两个机制：

  • is_visible 布尔字段 — 全局显示/隐藏
  • Model Compatibility — 运行时根据模型画像（instructional vs standard）过滤音色码集
关键缺失：没有「音色卡片」分组概念，没有公司级授权（类似 LLM 的 TenantLLMModelGrant），所有公司看到同样的音色列表。

设计 音色卡片系统设计

核心概念

🎴 音色卡片（Voice Card）

一组音色的逻辑分组，类似 LLM 的"供应商→模型"层级。

  • 每张卡片属于一个 TTSProvider
  • 卡片可包含 1 个或多个 TTSVoice
  • 卡片有独立名称、描述、图标
  • 卡片标注是否支持指令控制
  • 卡片分为「系统预置」和「定制音色」两类
🏢 公司授权（Tenant Voice Card Grant）

控制哪些公司可以使用哪些音色卡片。

  • 超管选择公司 → 勾选可用音色卡片
  • 可设置卡片在该公司的默认启用状态
  • 公司侧仅能看到已授权的卡片
  • 授权卡片中的音色才可供设备绑定

设计决策

#决策选择理由
1 音色卡片 vs 直接授权音色 卡片分组 与 LLM 供应商→模型层级一致，方便管理（一个卡片 = 一个场景）, 也便于"定制音色"类场景按批次授权
2 卡片与 TTSVoice 关系 一对多 一个卡片包含多个音色（如"中文女声包"包含 Cherry、Serena、Kiki），一个音色可属于多个卡片
3 定制音色存储 TTSVoice 扩展字段 定制音色也是 TTSVoice，只是 type=‘custom’，通过 voice-enrollment API 注册后同步到 DB
4 指令控制标识 卡片级 + 音色级 卡片标注是否整体支持（UI 展示），音色级做细粒度运行时校验

关键 UI 规则

  • 卡片分组展示 — 音色按卡片分组显示，每个卡片为一个视觉区块，卡片标题显示其名称和类型徽章（系统预置/定制音色）
  • 指令控制标识 — 卡片右上角显示 指令控制 ✓ 或 指令控制 -
  • 定制音色标识 — 定制音色卡片显示 定制 徽章，区别于系统预置
  • 默认音色高亮 — 当前公司默认音色在列表中高亮，显示"当前默认"标记
  • 设备绑定范围 — 公司用户只能从已授权卡片的音色中为设备绑定音色

模型 数据模型设计

新增模型

# backend/apps/ai_models/models.py

class TTSVoiceCard(models.Model):
    """音色卡片 — 一组音色的逻辑分组"""
    provider      = models.ForeignKey(TTSProvider, on_delete=CASCADE,
                                       related_name='voice_cards')
    name          = models.CharField('卡片名称', max_length=128)
    description   = models.TextField('卡片描述', blank=True, default='')
    icon_path     = models.CharField('卡片图标', max_length=255, blank=True, default='')
    card_type     = models.CharField('卡片类型', max_length=16,
                                      choices=[('system', '系统预置'),
                                               ('custom', '定制音色')],
                                      default='system')
    supports_instruction = models.BooleanField('支持指令控制', default=True)
    sort_order    = models.PositiveIntegerField('排序', default=0)
    is_active     = models.BooleanField('启用', default=True)
    created_at    = models.DateTimeField(auto_now_add=True)
    updated_at    = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ['sort_order', 'id']
        verbose_name = '音色卡片'
        verbose_name_plural = '音色卡片'

    def __str__(self):
        return f'{self.name} ({self.get_card_type_display()})'


class TTSVoiceCardItem(models.Model):
    """卡片-音色 关联表（多对多）"""
    card  = models.ForeignKey(TTSVoiceCard, on_delete=CASCADE,
                               related_name='card_items')
    voice = models.ForeignKey(TTSVoice, on_delete=CASCADE,
                               related_name='card_items')
    sort_order = models.PositiveIntegerField('排序', default=0)

    class Meta:
        ordering = ['card', 'sort_order', 'id']
        unique_together = [('card', 'voice')]
        verbose_name = '卡片音色关联'

    def __str__(self):
        return f'{self.card.name} → {self.voice.display_name}'


class TenantTTSVoiceCardGrant(models.Model):
    """公司音色卡片授权 — LLM TenantLLMModelGrant 的 TTS 等价"""
    tenant    = models.ForeignKey(Tenant, on_delete=CASCADE,
                                   related_name='tts_voice_card_grants')
    card      = models.ForeignKey(TTSVoiceCard, on_delete=CASCADE,
                                   related_name='tenant_grants')
    is_active = models.BooleanField('已授权', default=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        unique_together = [('tenant', 'card')]
        verbose_name = '公司音色卡片授权'
        verbose_name_plural = '公司音色卡片授权'

    def __str__(self):
        return f'{self.tenant_id}:{self.card.name} ({"✓" if self.is_active else "✗"})'

  • 运行时配置 — GET /api/v1/device-runtime/config/ 返回的 TTS 配置不受影响（已有音色 ID 即可合成）
  • WebSocket 实时 TTS — resolve_tts_voice() 需要校验音色所属卡片是否已被公司授权，否则拒绝使用未授权音色

// 新增 API 类型定义
export type TTSVoiceCard = {
  id: number;
  name: string;
  description: string;
  iconPath: string;
  cardType: 'system' | 'custom';
  supportsInstruction: boolean;
  sortOrder: number;
  isActive: boolean;
  voices: TTSVoiceRecord[];
  voiceCount: number;
};

export type TenantCardGrant = {
  cardId: number;
  cardName: string;
  cardType: string;
  isActive: boolean;
};

export type TenantCardGrantPayload = {
  cardGrants: Array<{ cardId: number; isActive: boolean }>;
};

// API 函数
export const fetchVoiceCards = async () => httpClient.get('/settings/tts/cards/');
export const createVoiceCard = async (payload) => httpClient.post('/settings/tts/cards/', payload);
export const updateVoiceCard = async (id, payload) => httpClient.patch(`/settings/tts/cards/${id}/`, payload);
export const deleteVoiceCard = async (id) => httpClient.delete(`/settings/tts/cards/${id}/`);
export const fetchTenantCardGrants = async (tenantId) => httpClient.get(`/settings/tts/tenants/${tenantId}/card-grants/`);
export const updateTenantCardGrants = async (tenantId, payload) => httpClient.patch(`/settings/tts/tenants/${tenantId}/card-grants/`, payload);

迁移 迁移路径

Phase 1: 数据模型 + 卡片管理（后端）

  1. 创建 TTSVoiceCard、TTSVoiceCardItem、TenantTTSVoiceCardGrant 模型 + 迁移
  2. 给 TTSVoice 增加 voice_type、source_audio、voice_params 字段 + 迁移
  3. 编写种子数据：将现有 20+ 个音色按场景划分为 4–6 个初始卡片（中文女生、中文男生、英文、方言等）
  4. 实现卡片 CRUD ViewSet + Serializers
  5. 实现公司授权 ViewSet + Serializers
  6. 注册 URL 路由

Phase 2: 超管前端改造

  1. 在 /settings/tts 页面新增 Tabs 组件（现有 + 音色卡片 + 公司授权）
  2. 实现音色卡片列表 + CRUD 弹窗
  3. 实现公司授权界面（参考 settings-llm 页面的公司授权模式）
  4. 适配定制音色上传流程

Phase 3: 公司端改造 + 运行时校验

  1. 修改 CompanyTtsOptionsView 返回按卡片分组的音色列表
  2. 修改 CompanyTTSSettingsWriteSerializer 校验 voiceId 属于已授权卡片
  3. 修改 ./tts-management/index.tsx 展示卡片分组 UI
  4. 修改 resolve_tts_voice() 运行时校验公司授权
  5. 修改 Device TTS 绑定接口仅展示已授权音色
  6. 添加测试覆盖（公司授权场景、跨公司隔离校验）
向后兼容：整个 Phase 1 不修改任何现有 API 响应，仅新增。Phase 2/3 逐步切换前端展示方式。在未分配卡片时，公司端仍然退化为平面音色列表（对所有可见音色做 flat 展示），确保数据迁移期零中断。
