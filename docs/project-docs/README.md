# Solin 数字人后台管理平台 — 项目文档套件

本目录是对 `could_frontend` 项目的系统性拆解与分析文档集合，面向新加入的开发、运维与产品人员，旨在提供一套完整、准确、可查阅的项目知识库。

所有文档使用中文编写，遵循统一的层级结构与专业术语。

## 项目简介

**Solin（索灵）** 是一个数字人后台管理平台，为数字人设备提供全生命周期管理：设备注册与授权、AI 智能体应用配置、多租户隔离、LLM/TTS/ASR 三大能力中心、知识库 RAG、控制指令派发、实时语音对话（HTTP + WebSocket 双通道）以及第三方会话机器人集成。

平台采用 **Django 5.2 + React 18 + Docker Compose** 技术栈，通过统一 WebSocket 入口承载设备实时能力，通过 REST API 承载后台管理能力。

## 阅读建议

- **新成员入门**：按 01 → 02 → 03 → 07 顺序阅读，配合本地 `docker compose up -d` 跑通环境。
- **后端开发**：重点阅读 02、03、05、06，配合 `backend/AGENTS.md` 与各 app 的 `AGENTS.md`。
- **前端开发**：重点阅读 02、03、05、09，配合 `web/AGENTS.md`。
- **运维部署**：重点阅读 07、08，配合 `docker-compose.yaml` 与 `caddy/Caddyfile`。
- **排查问题**：直接查阅 10，配合 `wiki/` 目录下的专题文档。

## 与既有文档的关系

本套件是对项目的高层系统性梳理，不替代以下既有文档：

- `AGENTS.md` / 各模块 `AGENTS.md`：AI 协作快速参考，记录模块级约定与反模式。
- `CONTEXT.md`：领域语言（Ubiquitous Language）权威定义。
- `wiki/`：专题深度文档（WebSocket、ASR、TTS、第三方机器人集成等）。
- `docs/adr/`：架构决策记录（ADR）。

当本套件与源码或上述文档冲突时，以源码与既有文档为准。
