# 03 — 核心功能模块解析

本章对后端 9 个业务 app 与前端 28 个页面模块逐一解析，说明职责、关键实现与协作关系。

## 3.1 后端业务应用

### 3.1.1 accounts — 账号与权限

**职责**：登录鉴权、JWT 签发与刷新、账号申请审批、权限点、菜单注入、强制改密。

**核心模型**：

- `AccountUser`：扩展 Django User，关联 `tenant`、`roles`、`force_password_change` 标记。
- `AccountApplication`：账号申请单（手机号唯一约束，状态机：待审核/通过/拒绝）。
- `Role` / `UserRole`：角色与用户角色绑定。
- `PermissionPoint` / `Menu`：权限点与菜单（后端为唯一事实来源，前端只展示与守卫）。

**关键机制**：

- `TenantAwareJWTAuthentication`：解析 JWT 并注入租户上下文。
- `/auth/me/`：登录后校准接口，返回 user + permissions + menus，前端据此渲染菜单与守卫。
- 账号申请 `phone` 字段唯一，重复提交返回友好提示"该手机号已提交过申请"。

**主要 API**：`/api/v1/auth/login/`、`/auth/refresh/`、`/auth/me/`、`/auth/account-applications/`、`/auth/account-applications/manage/`。

### 3.1.2 tenants — 多租户与员工

**职责**：租户（公司）管理、员工管理、租户隔离基础设施。

**核心模型**：

- `Tenant`：租户（公司），含 `name`、`is_active` 等。
- `Membership`：用户与租户的多对多关系，含 `is_tenant_admin` 标记。

**关键机制**：

- `TenantManager`（`apps/tenants/managers.py`）：所有业务模型 manager 基类，queryset 自动按租户过滤。
- `apps/tenants/mixins.py`：视图 mixin，create 时自动注入 `tenant`。
- 平台管理员通过 tenant scope 浏览；公司管理员仅见本公司。

### 3.1.3 devices — 设备管理

**职责**：设备注册、授权、分组、运行时配置、唤醒词、设备聊天日志、WebSocket 事件总线。

**核心模型**：

- `Device`：设备码 `code`（唯一，Android 生成）、名称、状态（online/offline）、绑定 `application` / `agent_application` / `tts_voice`、`tts_voice_config`（JSON）、`authorization_type`（permanent/trial）、`expires_at`、`tenant`、心跳字段。
- `DeviceApplication`：设备应用，聚合 resources / scrolling_texts / voice_tones / tts_voices / model_assets / command_groups，绑定 `agent_application`。
- `DeviceGroup`：设备分组。
- `WakeWord`：唤醒词（4–6 汉字，含编码 `encoded_text`、boost、threshold），M2M 关联 Device。
- `DeviceChatLog`：设备聊天日志，含 `runtime_session_id`、`answer_blocks`、`command_dispatch_diagnostics`、`knowledge_references`、`source`（http/websocket）。
- `DeviceAuthorization`：设备授权记录。

**关键服务**（`apps/devices/services/`）：

- `runtime.py`：`get_runtime_device(device_code)`、`get_ready_runtime_device`、`validate_runtime_application_active`。
- `chat_logs.py`：`record_device_chat_log`。
- `wake_words.py`：唤醒词编码（sherpa-onnx keyword line 生成）。
- `voice_pipeline_logging.py`：结构化语音管线日志。

**实时事件**（`apps/devices/realtime.py`）：

- `publish_device_event` / `add_device_event_subscriber` / `remove_device_event_subscriber`：设备事件发布订阅（基于内存 queue，按 tenant + device_code 过滤）。
- `build_device_runtime_config_event`：组装完整运行时配置事件。
- `mark_device_online_for_websocket` / `mark_device_offline_for_websocket` / `touch_device_for_websocket`：WebSocket 心跳驱动的在线状态。

**主要 API**：`/api/v1/devices/`（CRUD + stats）、`/device-runtime/config/`（设备运行时配置）、`/devices/{code}/voice-chat/`（HTTP 语音对话）、设备授权、设备聊天历史等。

### 3.1.4 ai_models — AI 能力中心

**职责**：LLM/TTS/ASR 三大供应商体系、Agent Application、聊天会话、第三方机器人、知识检索、流式输出。这是最复杂的 app。

**核心模型**：

- **LLM 体系**：`LLMProvider`（供应商，含 `api_base_url`/`api_key`/`api_protocol`）、`LLMModel`（模型，含 `enable_web_search`）、`TenantLLMModelGrant`（公司授权）、`TenantLLMSettings`（公司默认模型）、`LLMTestSettings`（测速配置）。
- **TTS 体系**：`TTSProvider`、`TTSVoice`（音色，含 `voice_code`/`display_name`/`is_visible`/`is_active`），设备绑定关系见 `Device.tts_voice`。
- **ASR 体系**：`ASRConfig`（含 `vad_threshold`/`vad_silence_duration_ms`/`is_active`）。
- **第三方机器人**：`ThirdPartyChatbotProvider`、`ThirdPartyChatbotApplication`（含 `external_application_id`）、`ThirdPartyChatbotIntegration`（方案实例，含 `scheme_type` A/B + `config` JSON）、`TenantThirdPartyChatbotGrant`（公司授权）。
- **知识模型**：`EmbeddingModel`、`RerankModel`、`BailianKnowledgeConfig`、`TenantKnowledgeModelSettings`。
- **Agent 应用**：`AgentApplication`（公司级，含 system_prompt、knowledge_documents/bases 绑定、`runtime_config()` 方法返回运行时配置）、`AgentAnnotation`（精确匹配标准回复，含 `hit_count`/`last_hit_at`）、`AgentSuggestedQuestion`、`AgentReplyBlock`。
- **会话**：`ChatConversation`（含 `runtime_backend_type`、`external_session`（JSON，存 `runtimeSessionId`）、`llm_model`/`third_party_chatbot`、`application`）、`ChatMessage`（role: user/assistant，`content_blocks`）。

**关键服务**（`apps/ai_models/services/`）：

- `llm_services.py`：`stream_llm_chat_completion`（httpx 异步流式）、`get_tenant_llm_settings`、`is_llm_model_effective_for_tenant`。
- `realtime_asr.py`：ASR 上游 WS 连接、`resolve_asr_realtime_connection`、`extract_transcript_payload`（含替换词、填充词过滤）、`load_asr_effective_input_timeout_seconds`。
- `realtime_tts.py` / `tts.py` / `tts_adapters.py`：TTS 适配器体系，按音色卡片路由协议，`stream_realtime_segments` / `stream_realtime_text`。
- `third_party_chatbots.py`：`send_chatbot_message` / `stream_chatbot_message` / `supports_streaming` / `is_chatbot_effective_for_tenant`。
- `agent_knowledge.py`：`retrieve_knowledge_context_with_media_and_references`（RAG 检索 + 媒体 + 引用）。
- `reply_blocks.py`：`text_to_blocks`、`serialize_reply_blocks`、`serialize_published_annotation_blocks`。
- `follow_up_suggested_questions.py`：追问问题生成。

**主要 API**：`/api/v1/ai-models/llm/options/`、`/settings/llm/providers/`、`/ai-models/chat/`（SSE 流式）、`/ai-models/tts/`（公司默认音色）、Agent Application CRUD、第三方机器人方案管理等。

### 3.1.5 resources — 资源与指令

**职责**：图片/视频/滚动字幕/音色/模型资产/控制指令/指令分组/点位。

**核心模型**：

- `Resource`（图片/视频基类）、`Image`、`Video`。
- `ScrollingText`：滚动字幕。
- `VoiceTone`：音色（旧体系，兼容）。
- `ModelAsset`：模型资产。
- `CommandGroup`：指令分组。
- `ControlCommand`：控制指令（含 `name`、`command_code`、`backend_send_enabled`、TCP/UDP 目标）。
- `Point`（点位，`point_*.py` 子领域）：运行时/序列化器/后台/视图各一份。

**关键服务**：

- `command_dispatch.py`：`try_dispatch_command`（本地置信度计算 + 策略路由：直接执行/LLM 确认/普通对话）、`build_command_dispatch_snapshots`。
- `feishu.py`：飞书 webhook 通知（指令变更）。

**子领域约定**：`apps/resources/point_*.py` 是点位子领域，改动需同步验证 `/commands/points/` 路由。

**主要 API**：`/api/v1/resources/images/`、`/resources/videos/`、`/resources/scrolling-texts/`、`/resources/voice-tones/`、`/resources/models/`、`/commands/groups/`、`/commands/control/`、`/commands/tasks/`、`/commands/points/`、`/commands/aliyun/`、`/commands/data/`、`/commands/export/...`。

### 3.1.6 knowledge_base — 知识库

**职责**：知识库文档上传、分块、向量化（pgvector）、检索、媒体资产绑定。

**核心模型**：

- `KnowledgeBase`：知识库（公司级）。
- `KnowledgeDocument`：知识文档（含 `processing_status`，状态边界：业务 API 不暴露写入，仅 Admin）。
- `KnowledgeDocumentChunk`：文档分块，含 `embedding_vector`（pgvector VectorField）。
- `KnowledgeMediaAsset`：绑定到知识库的资源项。

**关键机制**：

- 状态硬边界：`processing_status` 只走 `/admin/`，业务 API 不写入。
- 向量化任务走 Celery（`tasks.py`），调用 `EmbeddingModel`。
- 检索走 pgvector 余弦相似度 + 可选 Rerank。
- 下载（单文件 + bulk-download）返回原生二进制，是统一响应包络的例外。

**主要 API**：`/api/v1/knowledge-base/`（CRUD）、`/knowledge-base/bulk-download/`。

### 3.1.7 audit — 审计日志

**职责**：记录后台操作行为。

**核心模型**：`OperationLog`（含 `actor_display_name`、`actor_role_name`、`description`、`method`、`path`、`status_code` 等）。

**机制**：`OperationLogMiddleware` 放在 `AuthenticationMiddleware` 之后，响应阶段 `request.user` 已就绪，自动记录。

**主要 API**：`/api/v1/audit/...`（日志查询）。

### 3.1.8 app_updates — 应用更新

**职责**：Android 应用版本管理与更新提示，含 RSA 签名。

**核心模型**：`AppUpdate`（版本号、更新包、签名、`APP_UPDATE_SIGNATURE_TTL_SECONDS`）。

**配置**：`APP_UPDATE_PACKAGE_NAME`（默认 `com.lingzhi.digital`）、`APP_UPDATE_PRIVATE_KEY_BASE64` / `APP_UPDATE_PRIVATE_KEY_FILE`。

**主要 API**：`/api/v1/app-updates/...`。

### 3.1.9 error_codes — 错误码目录

**职责**：集中式错误码管理，特别是 WebSocket 实时错误码。

**核心模型**：`RealtimeErrorDefinition`（code + default_message）。

**机制**：`apps/error_codes/catalogue.py` 提供 `get_error_definition` / `get_error_definition_by_key` / `require_error_definition_by_key` / `internal_error_definition`，供 `config/realtime.py` 统一构造错误事件。

**主要 API**：`/api/v1/error-codes/...`（错误码目录读取）。

## 3.3 前端基础设施模块

### 3.3.1 路由与守卫（`router/index.tsx`）

- `AuthGuard`：未登录跳 `/login`。
- `GuestGuard`：已登录跳离登录页。
- `PermissionGuard`：基于 `permissions` 校验，无权跳转。
- 启动时调 `/auth/me/` 校准 token 与权限。

### 3.3.2 API 客户端（`api/client.ts`）

- axios 实例，baseURL 由环境决定。
- 请求拦截：注入 `Authorization: Bearer`。
- 响应拦截：401 清登录态 + 跳 `/login`；DEV 模式改写 `backend:8000/media/...` 为同源 `/media/...`。
- 默认 timeout 10s，长时操作调用处单独覆盖。

### 3.3.3 状态管理（`store/auth.ts`）

Zustand store，字段：`token` / `refreshToken` / `username` / `role` / `permissions` / `menus`。
localStorage 持久化；actions：`login` / `logout` / `hasPermission` 等。

### 3.3.4 布局（`layouts/dashboard-layout.tsx`）

- Sider + Header + Content 三段式。
- `useBreakpoint()` 检测移动端，切换为 Drawer 抽屉侧栏。
- 菜单数据来自后端 `/auth/me/`，前端不硬编码。

### 3.3.5 全局组件（`components/`）

- `brand-mark.tsx`：品牌标识。
- `status-tag.tsx`：统一状态标签（`type`: online/offline/active/inactive/bound/unbound/pending）。
- `chat-markdown.tsx`：无依赖 Markdown 渲染器（自实现，支持流式刷新）。
- `knowledge-references.tsx`：知识库引用展示。

## 3.4 模块协作全景

```
设备 ──X-Device-Code──▶ devices.runtime ──▶ ai_models.services (LLM/TTS/ASR)
   │                        │                      │
   │                        │                      ├─▶ knowledge_base (RAG)
   │                        │                      ├─▶ resources.command_dispatch
   │                        │                      └─▶ ai_models.third_party_chatbots
   │                        │
   └──WS /ws/realtime/──▶ config.realtime ──▶ devices.realtime (事件总线)
                                                │
Web ──JWT──▶ accounts ──▶ tenants (隔离) ──▶ 各 app ViewSet
                                                │
                                                └─▶ config.business_cache (缓存)
```
