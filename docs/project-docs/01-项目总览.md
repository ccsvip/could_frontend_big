# 01 — 项目总览

## 1.1 项目定位

**Solin（索灵智能）数字人后台管理平台** 是面向数字人设备运营方的统一管理后台。其核心使命是：让运营方能够高效地管理数字人设备、配置 AI 智能体应用、接入大模型与语音能力、维护知识库，并保障多公司（多租户）数据 100% 隔离。

平台服务两类终端：

- **后台管理端（Web SPA）**：供平台管理员、公司管理员、公司员工使用，完成设备、资源、模型、知识库、指令等配置。
- **数字人设备端（Android）**：通过 `X-Device-Code` 请求头或统一 WebSocket 入口，获取运行时配置、上报状态、发起语音对话。

| 术语 | 含义 |
|------|------|
| **Company User** | 公司工作区内的用户；公司管理员与员工业务功能一致，仅管理员能管理员工 |
| **Agent Application** | 公司级 LLM 应用，配置系统提示词、知识文档、运行时会话设置（不称"智能体/应用/AI 应用"） |

| **Device Chat Contract** | 设备运行时对话的稳定 HTTP 响应与 WebSocket 事件契约 |
| **Device Runtime Session ID** | 后端持有、设备维度的会话标识，区别于第三方上游 sessionId |
| **Agent Annotation** | 公司级精确匹配标准回复，命中时绕过模型生成 |
| **Agent Reply Block** | Agent 响应的有序片段：text / image / video |
| **Resource Library Item** | 公司级可复用图片/视频，供 Agent Reply Block 等引用 |
| **Knowledge Document** | 公司级知识库文档，可绑定到 Agent Application |
| **Knowledge Media Asset** | 绑定到知识库的资源项，作为 Agent 回答的辅助参考 |
| **Control Command** | 公司级控制指令，匹配后可派发 TCP/UDP 执行 |
| **Control Command Match Confidence** | 0–1 的确定性置信度，非 ASR/LLM 概率 |
| **Wake Word** | 公司级唤醒词，4–6 个汉字且以"你好"开头，通过 sherpa-onnx 唤醒设备 |
| **Provider Voice / TTS Provider** | TTS 供应商提供的音色 / TTS 供应商本身 |
| **Device TTS Voice Configuration** | 设备当前绑定的音色 + 播放控制（语速/音调/音量） |
| **Third-Party Chatbot Scheme** | 可复用的第三方机器人集成模式（方案 A / 方案 B） |

## 1.6 关键设计原则

1. **多租户 100% 隔离**：所有业务模型通过 `tenant` 外键关联，queryset 经 `TenantManager` 自动过滤；普通公司账号不得通过 query 参数越权。
2. **REST API 优先**：HTTP API 一律 REST 风格（名词复数、标准方法）；实时能力走统一 WebSocket。
3. **单一 WebSocket**：所有实时能力复用 `/ws/realtime/`，通过 `type` 命令路由，不新增业务 WS URL。
4. **配置即数据**：供应商、模型、音色、指令、知识库等均为数据库配置，环境变量仅作初始默认或兜底。
5. **统一响应包络**：DRF 异常经 `config/exceptions.py` 统一转 `{status, message, code, data?}`。
6. **ASGI 流式**：聊天流式、ASR、TTS 必须 `uvicorn` + `httpx.AsyncClient` + `async def`，不得回退 WSGI 或同步 generator。
7. **设计服务功能**：UI 遵循 Teal 青绿色主色（`#0f766e`），克制装饰，等宽对齐技术标识。

## 1.7 默认凭据与种子

容器首次启动时，`backend` 服务会自动执行：

- 数据库迁移 `python manage.py migrate`
- 创建超级管理员 `admin / admin123456`（仅当不存在时）
- 设备种子 `python manage.py seed_devices`
- 周期任务种子 `python manage.py seed_operations_periodic_tasks`

> ⚠️ 生产环境务必在首次启动后立即修改 admin 密码。
