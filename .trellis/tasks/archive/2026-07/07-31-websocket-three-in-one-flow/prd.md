# WebSocket 三合一逻辑与流程图

## 需求

- 梳理项目统一 WebSocket 入口中“​​三合一”实时逻辑的实际执行链路。
- 使用 GitNexus 查询相关执行流，并阅读关键源码确认连接、消息路由、鉴权/设备识别、订阅与响应边界。
- 使用 Excalidraw MCP 绘制一张能表达入口、三类业务分支、消息方向和关键返回事件的流程图。
- 在结果中标注源码入口、关键符号、协议 type/command 和不确定或需要进一步确认的部分。

## 约束

- 只做分析和可视化，不修改业务源码。
- 遵循仓库统一 WebSocket 入口约定，不把三合一误解为新增多个 WebSocket URL。
- 流程图以实际源码和 GitNexus 执行流为依据，避免仅凭命名推断。

## 验收标准

- 已完成 GitNexus 仓库上下文、概念查询、关键符号上下文和至少一个完整 process trace。
- 已阅读并交叉核对 WebSocket 路由、消费者/处理器及其关键调用源码。
- 已生成 Excalidraw 流程图并返回可查看结果或明确的图形输出。
- 已用简洁文字说明三条分支、统一入口、关键事件和主要边界。
